# Orbit (AetherMidi)

A visual MIDI music generator and interactive sequencer built for generative composition and sonic exploration.

## Live Demo

Play with the app online: **[https://pbaarn.github.io/orbit/](https://pbaarn.github.io/orbit/)**

## Features

- **Interactive Canvas**: Visual node-based generative MIDI triggering.
- **Audio Engine**: Real-time synthesizer powered by [Tone.js](https://tonejs.github.io/).
- **Editorial UI**: Clean layout built with Tailwind CSS and FontAwesome.
- **MIDI Export / Generation**: Interactive sequence generation and custom controls.

## Running Locally

Simply open `index.html` in any modern web browser, or serve it using any local HTTP server:

```bash
# Python 3
python3 -m http.server 8000

# or Node.js / npx
npx serve .
```
